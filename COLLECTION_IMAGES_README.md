<!-- Collection Images Documentation -->

Para añadir imágenes de fondo a las colecciones, necesitarás crear y colocar las siguientes imágenes en la carpeta:
/images/portfolio/

Imágenes necesarias:
1. collection-entry-level.jpg (Recomendado: 600x800px)
   - Debe ser una imagen que represente el nivel "Entry Level"
   - Por ejemplo: un vaso de whisky simple, cóctel básico, o bebidas para principiantes

2. collection-premium.jpg (Recomendado: 600x800px)
   - Debe ser una imagen que represente calidad premium
   - Por ejemplo: botellas de alta gama, copas elegantes, ambiente sofisticado

3. collection-exclusive.jpg (Recomendado: 600x800px)
   - Debe ser una imagen que represente exclusividad
   - Por ejemplo: ediciones limitadas, botellas únicas, ambiente de lujo

Las imágenes se mostrarán con una overlay oscura y el texto se superpone, por lo que es importante que:
- Tengan buen contraste
- No sean demasiado ocupadas en las zonas donde aparece el texto
- Sean de alta calidad (mínimo 600x800px para evitar pixelación)

Una vez que tengas las imágenes, simplemente colócalas en images/portfolio/ con los nombres exactos mencionados arriba.
